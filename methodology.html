Methodology

Six ranking models, each fit from this season's game results and run for both divisions.

How to read these rankings

Each division's rankings page shows the models it runs as tabs over the same team list. The models use different inputs and different mechanics, so they won't always agree. Some fit all of the season's games at once (Massey, KRACH, HockeyBT), one updates game by game (ELO), and two are fixed formulas (NPI, RPI). Some use goals scored, and others only wins and losses.

ELO

Men'sWomen's

A sequential rating that updates after every game, like chess ratings.

How it works

Every team starts from a baseline rating (carried over from a preseason prior). After each game the winner takes points from the loser: more for an upset, fewer for an expected win. The exchange is scaled by margin of victory and adjusted for home ice.

Main attributes

  • Updates game by game
  • Uses margin of victory
  • Home-ice adjustment
  • Order of games matters

Massey

Men'sWomen's

A least-squares rating: the set of ratings that best explains every game's goal differential.

How it works

Solves one linear equation per game (winner's rating minus loser's rating ≈ goal margin) for the single set of ratings with the smallest total error. Adds a fitted home-ice term, a rest/fatigue adjustment, and ridge regularization so teams with thin schedules don't get extreme ratings.

Main attributes

  • Fits the whole season at once
  • Uses goal differential
  • Home-ice and rest adjustments
  • Rating is in goals

KRACH

Men'sWomen's

A Bradley-Terry rating: the model family behind the NCAA committee's PairWise comparison tool.

How it works

Solves for a rating per team so that each team's expected number of wins against its actual opponents, rating_A / (rating_A + rating_B) summed over its games, equals its actual number of wins.

Main attributes

  • Fits the whole season at once
  • Wins and losses only
  • No home-ice or margin terms
  • Rating is a win-odds scale

NPI

Men'sWomen's

A reimplementation of the NCAA's Nutting Power Index, the committee's selection formula.

How it works

Combines a team's winning percentage (road wins weighted more than home wins) with strength of schedule, measured by opponents' winning percentage, and a bonus for wins over strong opponents, into a single index.

Main attributes

  • Formula, not a fitted model
  • Wins and losses only
  • Strength of schedule
  • Quality-win bonus

HockeyBT

Men'sWomen's

An extended Bradley-Terry model (Davidson-Beaver) with home ice and ties.

How it works

Uses the same core as KRACH and adds two fitted terms: a home-ice advantage, and a tie parameter so overtime and shootout games count as closer to a draw than a clean win. A prior keeps thinly-scheduled teams from drifting to extreme ratings.

Main attributes

  • Fits the whole season at once
  • Win / tie / loss outcomes
  • Fitted home-ice term
  • Regularized
Wikipedia: Bradley-Terry model

RPI

Men'sWomen's

The Ratings Percentage Index: a weighted blend of a team's record and its opponents' records.

How it works

RPI = 0.25 × own winning percentage + 0.50 × opponents' average winning percentage + 0.25 × opponents' opponents' average winning percentage, with road wins weighted more than home wins.

Main attributes

  • Formula, not a fitted model
  • Wins and losses only
  • Strength of schedule
  • Rating is a 0 to 1 index
